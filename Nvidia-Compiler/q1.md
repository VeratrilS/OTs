
# Maximum Weighted Path Score Between Leaf Nodes

**Nvidia OA, NIT Rourkela, Software Intern (Compiler ), 24 Oct 2026**

## Problem Statement

You are given a tree with **N** nodes, numbered **1** to **N**, connected by **N − 1** undirected weighted edges. The edge between nodes **u** and **v** has weight **w**.

A **leaf node** is a node connected to exactly one other node.

Between any two distinct leaf nodes **A** and **B** there is exactly one simple path. If that path has **K** edges with weights **w₁, w₂, …, wₖ**, its score is:

**Score(A, B) = PathSum(A, B) + MaxEdge(A, B)**

where:

- **PathSum(A, B)** = w₁ + w₂ + … + wₖ
- **MaxEdge(A, B)** = max(w₁, w₂, …, wₖ)

Find the **maximum score** over all pairs of distinct leaf nodes.

## Input Format

- The first line contains an integer **N**, the number of nodes.
- Each of the next **N − 1** lines contains three integers **u v w**, describing an undirected edge between **u** and **v** with weight **w**.

## Output Format

Print a single integer: the maximum score among all pairs of distinct leaf nodes.

## Constraints

- 1 ≤ N ≤ 2 × 10⁵
- The input forms a valid tree: it is connected, has N − 1 edges and contains no cycles.
- The original bounds on edge weights were not recorded.

## Sample

**Input**

```
5
1 2 10
1 3 20
2 4 30
2 5 40
```

**Output**

```
110
```

**Explanation**

The leaf nodes are **3**, **4** and **5**.

| Pair   | Path             | Edge weights | PathSum | MaxEdge | Score         |
| ------ | ---------------- | ------------ | ------- | ------- | ------------- |
| (3, 4) | 3 → 1 → 2 → 4 | 20, 10, 30   | 60      | 30      | 90            |
| (3, 5) | 3 → 1 → 2 → 5 | 20, 10, 40   | 70      | 40      | **110** |
| (4, 5) | 4 → 2 → 5      | 30, 40       | 70      | 40      | **110** |

The maximum score is **110**.
